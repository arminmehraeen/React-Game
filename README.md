# Rock Paper Scissors Game 🎮

A modern, animated Rock Paper Scissors game built with React, featuring beautiful UI, animations, and multiple game modes.

## Features ✨

- 🎯 Beautiful modern UI with glassmorphism effects
- 🎨 Multiple themes (Default, Dark, Neon)
- 🎵 Sound effects and vibration feedback
- 🏆 High scores system with persistent storage
- ⚙️ Customizable settings
- 🎮 Multiple difficulty levels
- ✨ Smooth animations and transitions
- 📱 Responsive design for all devices

## Game Modes 🎲

### Easy Mode
- Slower computer response
- More forgiving gameplay

### Normal Mode
- Standard gameplay
- Balanced difficulty

### Hard Mode
- Faster computer response
- More challenging gameplay

## Settings ⚙️

### Sound & Vibration
- Toggle sound effects
- Toggle vibration feedback (mobile devices)

### Themes
- Default: Classic purple-blue gradient
- Dark: Sleek dark theme
- Neon: Vibrant pink-purple theme

## High Scores 🏆

- Track your best performances
- View top 10 scores
- Persistent storage using localStorage
- Date tracking for each score

## Technologies Used 🛠

- React
- React Router
- Framer Motion
- Tailwind CSS
- React Icons
- use-sound

## Getting Started 🚀

1. Clone the repository:
```bash
git clone https://github.com/yourusername/react-game.git
```

2. Install dependencies:
```bash
cd react-game
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open [http://localhost:5173](http://localhost:5173) in your browser

## Building for Production 🏗

To create a production build:

```bash
npm run build
```

The build files will be created in the `dist` directory.
